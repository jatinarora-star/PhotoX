# PhotoX 📷

A clean, responsive **photography portfolio website** built with pure HTML & CSS — featuring a smooth animated sidebar navigation with **zero JavaScript**.


![PhotoX Preview](Screenshot.png)


---
---

## ✨ Features

- 🍔 **Pure CSS Hamburger Menu** — sidebar toggle using the checkbox hack, no JS needed
- 📱 **Responsive Layout** — adapts cleanly across screen sizes
- 🎨 **Font Awesome Icons** — used throughout the sidebar navigation
- 🔤 **Google Fonts (Poppins)** — clean, modern typography
- 📸 **Full-screen hero image** — immersive photography aesthetic
- 🔗 **Social media links** — Facebook, Twitter, Instagram, YouTube in the sidebar footer

## 💡 How the Sidebar Works

The sidebar toggle uses the **CSS checkbox hack** — a hidden checkbox toggled by clicking the hamburger label. CSS sibling selectors (`~`) show/hide the sidebar with a smooth transition. **No JavaScript required.**
